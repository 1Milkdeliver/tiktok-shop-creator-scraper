0 位达人

1 导入 Cookie ＋ 添加账号 ❓ 多账号指南

将 Cookie JSON 文件 拖到此处，或直接 粘贴 到下方输入框
📄
可添加多个账号 Cookie 实现多账号并发抓取 · 用 Cookie-Editor 扩展导出 JSON 后粘贴或拖入

2 浏览器模式

自动：优先连接常驻调试 Chrome(9222)，没有则开屏幕外真实窗口。Headless 模式兼容性有限，建议使用自动或真实窗口。
🌍 达人地区（Shop）
💡 选择达人所在的 TikTok Shop 站点。需使用对应站点店铺账号的 Cookie 登录，才能抓取该地区达人。

3 选择抓取对象

类目关键词
ID 直接抓，handle/链接会自动解析。单次上限 500 条（防风控），超过请分批抓取。
抓取模式
💡 快速模式约 3-7 秒/页，适合大批量筛选；完整模式额外抓每位达人的简介、合作邮箱、MCN 等（速度慢 2-3 倍），适合精挑合作对象。快速模式下详情字段为灰色不可选。
抓取范围
💡 只抓新的：与之前抓取去重，不重复抓同一达人，适合持续增量采集；全部重抓：重新抓取所有达人（含之前已抓的），用于更新 GMV、粉丝数等有时效的数据。
更新达人库字段
仅更新勾选的字段组；其他字段保留达人库中的原值。
