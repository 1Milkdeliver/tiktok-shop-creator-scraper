# v1.3.1 Creator Library compatibility baseline

Run the local compatibility checks with:

```powershell
node --test test/database-v131-compatibility.test.js
```

The test creates an isolated temporary SQLite database with the original v1
schema and one creator/job record. It then opens that file through the current
`CreatorDatabase` API and verifies that:

- the desktop application continues to use `<userData>/data/creators.db` as
  its default Creator Library location;
- migrations 1 through the current migration list are applied once, preserving
  the old creator and scrape-job records;
- a migrated database can still accept and read a current creator record.

This is a regression baseline only. It does not use or alter a real user
database, and it should run before changes to database startup, migrations, or
Creator Library persistence.
