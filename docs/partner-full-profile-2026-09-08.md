# 团长完整资料采集：实现与验收边界

2026-09-08：已核对 Partner Center 发布的前端代码。详情接口为
`POST /api/v1/oec/affiliate/creator/marketplace/4partner/profile`，
请求体使用字符串 `creator_oec_id` 和 `profile_types`；按后台的区域路由调用。
这不代表接口已经通过真实采集验证。

该次独立接口测试没有取得可用的真实详情响应，没有写入或删除生产达人库，也未替换正在使用的安装包。
先前联系方式测试成功不能作为完整详情接口成功的证据。

## 本地实现

达人库的补全面板新增两个选项：仅联系方式（保留默认行为）与完整资料＋联系方式（明确标注待实测）。
范围仍为当前筛选与所选地区的交集，只补全库中已存在的达人，不新建部分资料记录。

完整模式顺序：

1. 基础与机构资料 `[1, 6]`。
2. 带货、视频及直播指标 `[2]`。
3. 粉丝画像 `[3]`。
4. 趋势 `[4]`。
5. 示例视频 `[5]`。
6. 使用原有联系方式接口读取各类联系方式。

所有已授权返回的详情字段、扩展字段和统计区间信息保留在 `partner_details_json`；趋势明细另存 `partner_trend_json`。
常见字段有独立列，其他返回字段仍可从完整 JSON 核查。
头像与视频仅保留接口提供的资料/链接，不下载媒体文件；“示例视频”不等于该达人全部历史视频。

平台明确不授权的包装字段不保存其值。不猜测邮箱、电话区号、地区或缺失指标。
保留币种、原始值、格式值与区间；`RM10K+` 不写成精确 GMV。
采集站点 `partner_market` 与接口返回的达人地区 `selection_region` 分开。

每个模块完成后独立更新现有记录，另记字段状态、检查时间和内部断点。
停止、验证码、限流、会话失效、格式不符或写库失败均不计为整位达人完成。
再次启动默认只补未完成模块；取消“跳过已检查”可重新检查全部模块。
“全部模块已检查”只表示请求与保存流程完成，不保证每个字段有值。
平台本次未提供的字段保留原值，但在本次字段状态中标明未提供/无权限，避免把旧值误当新值。

测试使用临时 SQLite 和合成响应，覆盖资料/联系方式串联、断点续抓、错误停止、地区隔离、旧值保留、金额区间、字段目录、CSV/Excel 导出。
离线通过不证明平台真实接口可用、长期稳定或每个账号均有权限。

## 后续正常页面实测（2026-09-08 晚间）

用户确认 Cookie 相同后，改为在用户已登录的侧边栏浏览器中正常打开详情页。
页面确实显示基础资料、销量、合作指标、视频/直播指标及粉丝画像；并非只有联系方式。
此事实仅证明该浏览器页面可用，不能证明独立 HTTP 请求可用，也不能归因于 Cookie 过期。

通过受支持的浏览器界面读取并核对了一个既有 MY 达人：分别检查“全部视频/直播”和“仅带货视频/直播”，随后还原开关。
没有读取隐藏应用状态或浏览器 Cookie，没有发送消息、邀请或收藏，没有规避验证。
测试中的软件浏览器探针启动被执行环境拒绝，没有运行该探针；未通过其他启动方式重试。

- 全部内容和带货内容指标分开存储；页面明确显示的统计时间另存，不将其擅自命名为固定 30 天。
